# nachitomanzur.github.io

The favicon is a water detail from Claude Monet's *La Grenouillère* (1869),
in The Metropolitan Museum of Art. The [source reproduction](https://commons.wikimedia.org/wiki/File:La_Grenouill%C3%A8re_MET_DT833.jpg)
is available under CC0. The square crop starts at (2400, 2150) and measures
440 × 440 pixels in the 3811 × 2880 source image.
